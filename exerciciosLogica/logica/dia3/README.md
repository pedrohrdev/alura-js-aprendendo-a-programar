# 🏆 10 — DESAFIO DO DIA

## Sistema de pagamento

Você está criando a lógica de um pequeno sistema de pagamento.

O programa recebe:

* preço de um produto;
* quantidade comprada;
* porcentagem de desconto.

Depois deve calcular:

1. O valor total sem desconto.
2. O valor do desconto.
3. O valor final da compra.
4. Quanto cada pessoa pagaria caso a compra fosse dividida igualmente entre 3 pessoas.

### Exemplo

```text
Produto: R$ 80
Quantidade: 4
Desconto: 10%

Valor sem desconto: R$ 320
Desconto: R$ 32
Valor final: R$ 288
Dividido entre 3 pessoas: R$ 96
```

### ⚠️ Regras

Resolva utilizando apenas os conceitos estudados até agora.

**Não use:**

* bibliotecas externas;
* funções prontas para resolver toda a lógica;
* código copiado;
* soluções encontradas na internet.

A ideia é você construir a lógica.

---

## 🔥 Desafio extra

Depois de terminar, altere o programa para receber também a quantidade de pessoas que irão dividir a compra.

Agora o programa deverá calcular:

```text
valor por pessoa = valor final / quantidade de pessoas
```

Teste com diferentes quantidades.
